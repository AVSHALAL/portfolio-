# Portfolio d’Amara Bathily

Site statique en français : HTML, CSS et JavaScript sans dépendance externe.

## Structure

- `dist/index.html` : parcours, projets, stage, matrice de compétences, contact.
- `dist/veille.html` : veille Fortinet, chronologie 2025–2026 et méthode de suivi.
- `dist/assets/style.css` : mise en page responsive et impression.
- `dist/assets/app.js` : fiches projets, filtres, menu mobile et impression.

## Contenu et sources

Les informations de parcours et de stage proviennent d’Amara. Les AP communs ont été identifiés dans le dépôt d’exemple fourni : https://github.com/wizanagracis-sys/etude (consulté le 11 octobre 2026). Le contenu du site est rédigé indépendamment de son code ; les résultats, dates de stage, budgets et niveaux de maîtrise du camarade ne sont pas attribués à Amara.

La veille s’appuie sur quatre publications officielles du CERT-FR, accessibles depuis les fiches. La documentation Docker rappelle les limites de l’isolation : https://docs.docker.com/engine/security/.

## Compléments à fournir pour la présentation

- Dates exactes du stage et de la formation.
- Captures personnelles, fichiers `.pkt`, configurations et comptes rendus de tests.
- Notes datées des prochains suivis de veille.

L’absence de ces preuves est indiquée dans les fiches concernées. Aucun suivi rétrospectif sur deux ans, déploiement de correctif en production ou diplôme supplémentaire n’est inventé.
